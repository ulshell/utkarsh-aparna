# Utkarsh & Aparna — Wedding Invitation

Ready for GitHub Pages (`https://ulshell.github.io/utkarsh-aparna/`).

## Quick Setup
1. Save the 4 Radha-Krishna artworks into the `images/` folder as:
   - `images/hero.png` (or `hero.jpg`)
   - `images/haldi.png` (or `haldi.jpg`)
   - `images/sangeet.png` (or `sangeet.jpg`)
   - `images/vivah.png` (or `vivah.jpg`)
2. (Optional) Drop your preferred Krishna flute MP3 into `audio/krishna-flute.mp3`.
   If left empty, the built-in Krishna Bansuri synthesizer plays automatically.
3. Upload all files to your public GitHub repository `utkarsh-aparna`, then enable **Settings -> Pages -> Deploy from branch (`main`, `/ (root)`)**.
